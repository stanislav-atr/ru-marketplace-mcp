## 3. Hard-won Lamoda facts (verified live 2026-09-24)

- Search/catalog page state: `window.__NUXT__.payload.state.payload` → `products` (60/page:
  `sku, name, model_name, brand.name, color_family, colors, gallery[], price_amount, prices[], is_sellable, sizes[{size, brand_size, is_available}], seasons, rating{0-100 scale}`),
  `facets` (`colors, size_values, brands, base_materials, filler_materials, property_style, print, property_production_country, availability, store_warehouse, is_sale, price(range), is_wide_shoes`),
  `pagination{page,pages,limit,found}`, `sort.values` (`default,new,price_desc,price_asc,new_sale,discount`), `category_tree`.
- Product page state: `payload.product` → `title`, `model_title` (grid uses `model_name`!),
  `brand.title` (grid uses `brand.name`!), `colors[{id,title}]`, `gallery`, `images[]` (type `tryoff`
  = garment-only shot, useful for C), `price` (current), `old_price`, `prices.loyalty_base.price` ("31 398"),
  `sizes[{title, brand_title, stock_quantity, primary_description}]`, `attributes[{title,value}]`,
  `description`, `average_rating` (1–5), `counters.reviews`, `colored_products[{sku, colors, gallery, is_in_stock}]`.
- Prices: grid `price_amount` = **current** price; ladder `prices[0]` = original; discount types
  `onsite`, `onsite_promo` (public) and `loyalty` (Lamoda Club — reported apart, never everyday).
- URL filters (comma-joined IDs, verified): `colors`, `size_values`, `brands`, `page`, `sort`.
  Gender scoping: `/c/4152/default-men/?q=…`, `/c/4153/default-women/?q=…`. Men's clothing `/c/477/…`.
  Colour IDs: синий 643, голубой 859, хаки 3847, зеленый 637, черный 645, серый 635, бежевый 647,
  коричневый 641, белый 615, молочный 44054, бордовый 3865, бирюзовый 30862 (full table in catalog.py).
  No olive family: olive is split across хаки and зеленый; labels are seller-assigned families.
- Unknown URL params are silently ignored by Lamoda → B must verify each filter applied
  (facet `is_forced`/checked state or `total_found` change), never assume.
- CDN `a.lmcdn.ru`: only `img46x66`, `img236x341` (~13 KB), `img389x562` (~31 KB), `img600x866`,
  `product` (full); other sizes 400. Image files are named after the SKU; the image id is not derivable.
- GraphQL `POST /goapi/v2/catalog/graphql/products/` returns 403 "Запрос отклонен" from this
  network (curl and httpx), while Chrome reads the same host fine. Page tier is the real card tier.
- Product pages slowed past the 20 s nav timeout after ~20 loads in a burst; recovered in minutes.
  Pacer contract: timeouts are NOT refusals (don't feed them to `record_refusal`).
- Claude Desktop drops the text blocks between MCP images → labels must be in the image (done: sheet).
- Query wording matters: "ветровка с капюшоном" good; "куртка мембранная" returns insulated parkas.
  Lamoda names garments loosely (Harrington may be "Бомбер", "Ветровка", "Куртка-рубашка").
